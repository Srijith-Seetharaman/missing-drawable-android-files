The files that I have placed in this repo are those that need to be pasted into an Android application, if one chooses to create it in IntelliJ IDEA Ultimate Edition with all officially published Android plugins installed and enabled.

All uou need to do is:

1. unzip it, and 
2. move the contents of the folder into `app\src\main\res`,

and you should be able to build a new `Empty Activity` project in IntelliJ IDEA
